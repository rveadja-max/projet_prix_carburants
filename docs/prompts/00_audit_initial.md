# Prompt 00 — Audit initial du dépôt et plan de travail

Lis d'abord `CLAUDE.md`, `README.md` et les documents de cadrage. Inspecte le dépôt existant sans modifier de fichier et sans installer de dépendance.

Produis :
1. état réel de l'environnement Ubuntu/WSL, Python et Git ;
2. arborescence et fichiers existants ;
3. exigences satisfaites, partielles, absentes ou inconnues ;
4. risques bloquants ;
5. plan d'exécution par petites étapes avec critères d'acceptation ;
6. commandes exactes proposées, en distinguant celles déjà exécutées de celles à exécuter.

Ne suppose pas que les fichiers du kit sont déjà dans le dépôt. N'invente pas de résultats. Attends validation avant les modifications structurelles.
